# outcms
# 🦊 FoxHomeAIO

Единый рабочий инструмент для управления бригадой: база сотрудников, заявки склада,
график смен, бланки учёта услуг, пропуска, письма и списки на КПП — всё в одном HTML-файле.

**Один файл. Ноль зависимостей. Ноль установки.** Просто откройте `cmsaut.html` в браузере —
и всё работает, включая оффлайн.

---

## 🚀 Возможности

### 👥 Сотрудники
- База сотрудников: ФИО, навыки (мультивыбор), признак «Техника», ставка, телефон.
- Импорт списка из Excel-файла, поиск, фильтры и сортировка.

### 📋 Заявки склада
- Пошаговое создание заявки: параметры → роли → назначение сотрудников → подтверждение.
- Печать/сохранение заявки в PDF одной кнопкой.

### 🗓️ График работы
- Смены День / Ночь / Выходной по сотрудникам.
- Экспорт/импорт данных (JSON и Excel) в Настройках.

### 🗒️ Бланк учёта услуг
- Заполнение бланка смены, распределение часов по сотрудникам, печать.

### 🪪 Пропуска
- Генератор пропусков 5×7,5 см: фото + данные в готовую карточку.

### ✉️ Письма
- Компоновка письма с вложениями, предпросмотр, сохранение в `.eml`, сборка ZIP-архива.

### 📄 PDF
- Сборка PDF из фотографий с сортировкой файлов.

### 🛂 Список КПП
- Таблица: ФИО, дата рождения, гражданство, серия/номер паспорта, дата 1-й смены, телефон, транспорт.
- Экспорт в Excel
- Импорт любого .xlsx
- Импорт из базы сотрудников и обратный перенос списка в базу (ФИО + телефон, дубли пропускаются).

### ⚙️ Настройки
- Тёмная / светлая тема.
- Широкая или компактная рабочая зона (запоминается).
- Резервная копия: экспорт/импорт всех данных одним JSON-файлом.
- Полный сброс к заводским настройкам.

## 🧱 Как это устроено

- **Один самодостаточный HTML-файл**: модули встроены в оболочку и загружаются лениво в iframe
  (srcdoc, same-origin) — единый стиль, тема и высота подстраиваются автоматически.
- **Данные** — в `localStorage` браузера (сотрудники, заявки, график, КПП, настройки),
  резервная копия выгружается в JSON.
- **Оффлайн-генерация Office-документов** — xlsx собирается вручную из XML-частей и упаковывается
  в ZIP собственным кодом; чтение xlsx обратно — собственный ZIP/DEFLATE-парсер.
  Никаких CDN, сборщиков и серверов.
- **Адаптив**: от ноутбучных 1366px до широких мониторов — рабочая зона тянется, лишние поля убраны.

## 📖 Начало работы

1. Скачайте `cmsaut.html`.
2. Откройте двойным щелчком в любом современном браузере (Chrome / Edge).
3. Добавьте сотрудников на вкладке «Сотрудники» — дальше модули подхватят базу автоматически.

> ⚠️ Данные хранятся в localStorage выбранного браузера. При очистке данных сайта или смене
> браузера/компьютера сделайте резервную копию в «Настройках» и восстановите её там же.
